# Degrau — pesquisa e MRD de app educacional infantil (4–8 anos)

Leitura (alfabetização em Português Brasileiro), Lógica, Matemática e Inglês, inspirado nos princípios do
Método Kumon e em técnicas consagradas de alfabetização e ensino de matemática.

| [`docs/02-MRD-prompt-app-degrau.md`](docs/02-MRD-prompt-app-degrau.md) | MRD em formato de prompt, pronto para colar em um assistente de IA ou entregar ao time de produto. |

## Rodar o app

```bash
cd app && npm install && npm run dev
```

> "Kumon" é marca registrada do Kumon Institute of Education. Este projeto não é afiliado ao Kumon e usa
> apenas princípios pedagógicos gerais.
